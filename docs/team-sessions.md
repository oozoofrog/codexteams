# 팀 기본 화면과 세션 조회

일반 텍스트를 팀에 위임하는 모드와 중단·재개는 [팀 모드 안내](team-mode.md)를 참조하세요.

`/teams` 또는 root의 `/teams home`은 팀 기본 화면을 엽니다. 목표 없이 TTY에서 `codexteams`를 시작해도 같은 화면이 열립니다. 현재 실행, 검증, 마지막 관찰과 작업 목록을 확인하고 방향키와 Enter로 행동을 선택합니다. Esc는 이전 화면으로 돌아가거나 기본 화면을 닫습니다. 화면을 닫아도 실행은 중단되지 않습니다. 중단하려면 현재 진행에서 명시적으로 중단을 요청하세요.

작업 결과는 최근 실행의 최종 응답을 먼저 표시합니다. 수정 요청에는 비어 있지 않은 지시가 필요합니다. 다시 시도와 결과 수락은 명시적 행동입니다. 수락 확인은 테스트 통과나 모델 종료와 별개입니다. 새 작업은 대기 상태로만 추가됩니다. 일괄 실행 중 추가한 작업도 현재 실행에 자동 편입되지 않습니다. 다음에 명시적으로 시작해야 합니다. 모델이나 인증 오류가 표시되면 Pi의 `/login` 또는 `/teams profile`을 확인하세요. 조회 화면에서 Esc로 복귀하면 root 전환 후 기본 화면이 열립니다.

`/teams sessions`는 현재 프로젝트와 이 Pi 프로세스에 연결된 팀을 root와 계획·작업의 계층으로 표시합니다. 선택한 항목의 프로젝트 ID와 canonical 경로가 표시됩니다. ↑/↓와 Enter로 조회할 작업을 선택합니다. 긴 경로는 ←/→로 이동해 확인합니다. Esc는 선택을 취소하거나 조회를 닫고 팀 root로 돌아갑니다. `/teams open <task-id>`로 ID를 직접 지정하고 `/teams home`으로 팀에 돌아갈 수도 있습니다. 여러 팀에 같은 ID가 있으면 목록에서 선택하세요.

목록과 조회는 worker를 시작하거나 재개하지 않습니다. 결과를 수락하지도 않습니다. 원본 worker 세션은 읽기만 합니다. 조회 세션은 별도의 Pi 세션이며 읽기 전용입니다. 작업 변경, 검증, 재개와 수락은 팀 화면에서 명시적으로 실행합니다. 이 경계는 이 확장만 사용하는 지원 구성의 동작입니다. 같은 사용자 권한의 다른 프로세스나 악성 확장에 대한 OS sandbox가 아닙니다.

실행 중인 worker와 검증은 같은 Pi 프로세스에서 new·resume·fork 전환을 지나 계속 실행합니다. 종료와 reload는 실행을 정리합니다. 전용 `codexteams` launcher는 확장을 절대 경로로 명시하고 자동 발견을 끕니다. 프로젝트 전용 자동 발견으로 로드한 경우에는 실행 중 다른 프로젝트로 이동할 수 없습니다. 이때는 실행을 취소하지 않으며 launcher 사용을 안내합니다.

조회 파일은 Pi의 현재 세션 디렉터리에 저장합니다. 저장된 조회 세션으로 Pi를 시작하거나 native `/resume`으로 돌아오면 조회 화면을 다시 엽니다. 조회 화면의 실행 이력은 각 시도의 ID, 결과, 모델, 시각과 오류를 표시합니다. `PageUp`과 `PageDown`으로 이력 페이지를 바꾸고 ↑/↓로 내용을 이동합니다. 원본이 아직 없거나 누락되면 해당 상태를 구분해 표시합니다. 원본 실행 이력을 지우지 않습니다. `--no-session`에서는 파일을 만들지 않고 영속 조회가 불가능하다고 안내합니다. 비대화형 모드에서는 목록을 출력하지만 조회 화면을 열지 않습니다. 조회는 공개 메시지와 도구 기록만 표시하며 thinking과 reasoning은 표시하지 않습니다.
